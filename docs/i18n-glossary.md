# Translation glossary

Translators use these terms everywhere — core, modules, help, tours, notifications, emails. Keep them identical across files. When a term is missing, translate it consistently and add it here.

Style rules:
- **ky (Кыргызча):** modern business Kyrgyz in Cyrillic with ң, ө, ү. Polite «Сиз» to the user. Keep established Russian loanwords used in Kyrgyz offices (портал, модуль, файл, сервер, договор is «келишим»). No Latin script.
- **tr (Türkçe):** formal «siz», sentence case, standard Turkish business-software terms (as in Turkish localizations of Microsoft 365, Bitrix24).
- **zh (简体中文):** Simplified Chinese, concise UI style, no spaces between Chinese and digits unless a unit; use full-width punctuation in sentences, half-width in codes.
- Product and module proper names that are brand-like (Masterplan) are translated as listed below; keep codes, URLs, placeholders `{name}` and Markdown untouched.
- Buttons are verbs in imperative/infinitive per language convention (ky: imperative polite «Сактоо» style nouns are OK for short buttons; tr: «Kaydet»; zh: «保存»).
